# Diário de Saúde (Atlas Saúde)

App do celular para a família registrar o dia a dia: comida, insulina, glicose, sintomas, sono e emoções. Ele mostra relatórios para levar ao médico.

- **Os dados ficam só no celular**, no navegador. Este repositório tem apenas o código.
- O app **não sugere dose** e **não avalia valores**: só registra e mostra o que foi anotado.
- A **voz** vem desligada. Quando ligada, o áudio de "Falar para anotar" é transcrito pelo Google (Chrome).

Código-fonte e testes: `Atlas-solucoes/atlas-star`, nas pastas `projetos/diario-saude` e `tests/diario-saude`. Esta cópia é só para publicação.
